# 🧠 NeuroLens — Brain MRI Classification

NeuroLens is an AI-powered web application that uses deep learning to classify brain MRI images into four categories. It combines a web interface with a PyTorch image classification model.

## 🚀 Features

* Upload brain MRI images for classification.
* Predict one of four image categories.
* Display prediction confidence and class scores.
* Simple web interface built with HTML, CSS, and JavaScript.
* Flask backend for image processing and model inference.
* PyTorch-based deep learning model.

## 🧠 Classification Categories

The application predicts one of these categories:

1. **Glioma**
2. **Meningioma**
3. **No Tumor**
4. **Pituitary Tumor**

## 🛠️ Technologies Used

* Python
* PyTorch
* Torchvision
* Flask
* HTML
* CSS
* JavaScript
* Pillow
