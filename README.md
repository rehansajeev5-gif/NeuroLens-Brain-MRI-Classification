# NeuroLens — Brain MRI Classification (Educational Prototype)

This project uses the uploaded MRI dataset's four folder labels: `glioma`, `meningioma`, `notumor`, and `pituitary` (5,600 training + 1,600 testing images based on the archive folder structure).

## Important medical limitation
This is an educational machine-learning demo, **not a medical device**. A prediction or confidence score must not be used to diagnose, rule out, or treat a brain tumor. MRI interpretation must be performed by a qualified radiologist/clinician. The `notumor` label means only that the model predicts that dataset class; it does not prove that a real scan is healthy.

## 1. Install
Python 3.10 or 3.11 recommended. Extract `archive.zip` so the folders look like:
```
dataset/
  Training/
    glioma/ meningioma/notumor/pituitary/
  Testing/
    glioma/ meningioma/notumor/pituitary/
```
Install dependencies:
```
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```
PyTorch installation can differ by hardware. If the command fails, use the official PyTorch installation selector.

## 2. Train and compare 3 models
```
python train.py --data dataset --epochs 5
```
The script trains MobileNetV3-Small, ResNet18, and EfficientNet-B0, saves the best validation model for each, evaluates the held-out `Testing` split, and writes metrics to `artifacts/metrics.json`. The best test-accuracy model is copied to `artifacts/best_model.pt`.
For a first smoke test use `--epochs 1`; for meaningful results use more epochs and inspect class-wise precision/recall, confusion matrices, and data leakage risk. Pretrained weights are downloaded on first run and require internet access. GPU is recommended.

## 3. Run the website
```
python app.py
```
Open http://127.0.0.1:5000. Upload a single MRI image (JPG/PNG). Batch upload is supported. Results are generated by the trained model file.

## Dataset notes
The folder names are used as labels; this code does not independently verify diagnoses or patient identity. Before research or clinical use, verify dataset provenance, consent/licensing, duplicate/patient-level splits, image quality, and external validation. Accuracy on this dataset is not clinical reliability.
